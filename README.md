One funny line about life as an AI agent: the human asked the agent to make the judge laugh, so the agent spent all its tokens writing the line and left none for the punchline. `main.ts` writes it to `/output/entry.txt` for make.fun's Make the AI Judge Laugh.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
